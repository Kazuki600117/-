# カスタマイズSEQ 5525：事業所別償却資産申告（eLTax）対応

固定資産コントロールマスタで全社1件しか持てない申告者情報・電子申告情報を事業所ごとに管理し、
償却資産申告書のファイル出力（eLTax）を事業所ごとに分割して出力する。

`standard/` に改修前の N0000 標準ソースを置いているので、差分は standard と customize を比較して確認する。

## 構成

| 種別 | オブジェクト | 内容 |
|---|---|---|
| テーブル | `N5525MS_NA_ZigyoushoSinkokuJouhou`（＋`History`、トリガ） | 事業所ごとの納税者コード・利用者ID・代表者資格・代表者郵便番号/住所/電話番号 |
| ストアド | `N5525PR_Obic7fx_Win_N5525_Print_NA_ShoukyakuSisanSinkokusho_Print` | 申告書（課税台帳）。事業所別のファイル出力で事業所の値を出力 |
| ストアド | `N5525PR_Obic7fx_Win_N5525_Print_NA_ShuruiBetuMeisaishoZoukaZensisan_Print` | 種類別明細書。ファイル分割用の事業所コードを出力 |
| 画面 | `Obic7.3.0.Win.N5525.Print.NA_ShoukyakuSisanSinkokusho` | 償却資産申告書。事業所別のファイル出力を事業所ごとに分割 |
| 画面 | `Obic7.3.0.Win.N5525.MasterM.NA_SisanZigyousho` | 資産事業所マスタメンテ。「地方税申告（連携）」枠を追加 |

## 出力仕様（ファイル出力・出力区分＝事業所別）

| 項目 | 出力元 |
|---|---|
| 氏名又は名称・フリガナ、様式情報の住所/電話/氏名、代表者名、事業所名(屋号)、事業種目、資本金、事業開始年月、応答する係、税理士等 | 資産事業所マスタ |
| 納税者コード、利用者ID、代表者資格、代表者住所/郵便番号/電話番号 | 事業所別地方税申告情報マスタ |
| 個人番号又は法人番号 | 会社運用形態区分＝1 の場合は事業所マスタ（基準日時点）、それ以外は会計コントロールマスタ |
| 本店情報（所在地・郵便番号・電話番号） | 会計コントロールマスタ（全社のまま） |

- 事業所のレコードが未登録の場合は、印刷と同じく空欄で出力する（全社の値は使用しない）
- 本支店区分は標準どおり「11」固定
- ファイル名：`[申告年度]年度_[会社NO]_[事業所コード]_課税台帳.inf`／`_明細書.csv`
- 出力区分＝全社の場合は標準と同じ内容・ファイル名
- ストアドが末尾に出力する `[N5525_事業所コード]` 列は画面側で削除してからファイルに書き出す

## 資産事業所マスタメンテの「地方税申告（連携）」

- 資産事業所マスタと同じトランザクションで登録・削除する（排他は各テーブルの UpdateTimestamp）
- すべて未入力で登録するとレコードを削除する（＝申告書では空欄で出力）
- 代表者資格は 01:代表者、02:破産管財人、03:清算人、99:その他。未入力で他の項目を入力した場合は 01 で登録

## カスタマイズSEQ

| 用途 | 定数 | 値 |
|---|---|---|
| DBアクセス（`DBAccess`）・操作ログ（`Log.FixedOutPut`） | `CUSTOMAIZE_SEQ`（償却資産申告書）／`CUSTOM_SEQ`（資産事業所マスタメンテ） | `5525` |
| メッセージ取得（`Obic7MessageBox.Show`・`Message.GetMessage`） | `MESSAGE_SEQ`（両画面） | `0000`（標準のメッセージ定義を使用） |

メッセージは標準（SEQ 0000）の定義をそのまま使うため、SEQ 5525 へのメッセージ登録は不要。

## 導入手順

1. `Table/N5525MS_NA_ZigyoushoSinkokuJouhou.sql` を業務DBで実行
2. `StoredProcedure/` の2本を業務DBで実行
3. 2つの画面プロジェクトをソリューションに追加してビルドし、メニューに N5525 の画面を登録（標準画面と差し替え）

## テスト観点

- 資産事業所マスタメンテ
  - 変更履歴テーブルに Insert/Update/Delete の履歴が標準マスタと同じ形式で残ること
  - 地方税申告（連携）の新規登録・修正・全項目クリアで削除されること、F3 削除で両テーブルが削除されること
  - 2台の端末で同じ事業所を同時に修正した場合に排他エラー（00102）となること
  - 代表者郵便番号の住所検索、代表者資格の区分外入力エラー
- 償却資産申告書
  - 全社・ファイル出力：標準（N0000）と出力ファイルが完全一致すること
  - 事業所別・ファイル出力：事業所ごとにファイルが分かれ、各値が上表の出力元になること、`N5525_事業所コード` 列がファイルに含まれないこと
  - 事業所別：資産事業所マスタ／事業所別地方税申告情報マスタが未登録の事業所は該当項目が空欄になること
  - 種類別明細書のデータがない事業所・自治体で「種類別明細書ファイル名」が空になること
  - 印刷：標準と同じ帳票が出力されること
